# LoL-CounterForge

LoL CounterForge is a League of Legends champion matchup and counter-reference website designed to help players quickly explore champion counters, matchups, and useful champion information.

## Features

- Champion search
- Champion matchup information
- Counter and countered-by lists
- English and Korean language support
- Champion splash/icon data from Riot Games Data Dragon
- Responsive design for desktop and mobile
- Dark, competitive-style interface
- Fast client-side champion filtering

## Data

Champion information and artwork are loaded using Riot Games' Data Dragon service.

## Technologies

- HTML5
- CSS3
- JavaScript
- Riot Games Data Dragon API
